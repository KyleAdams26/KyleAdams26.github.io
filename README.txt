MULTI-PAGE SITE SETUP

1. Copy your current headshot into:
   assets/headshot1.png

2. Replace YOUR_EMAIL_ADDRESS in contact.html.

3. Keep all files in the repository root:
   index.html
   about.html
   research.html
   contact.html
   style.css
   script.js
   assets/headshot1.png

4. Preview locally:
   python3 -m http.server 8000

5. Open:
   http://localhost:8000

6. Publish:
   git add .
   git commit -m "Convert portfolio to multi-page website"
   git push
